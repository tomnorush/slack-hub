Privacy policy

slack-hub is a personal tool with a single user: the person who runs it on their own computer. This policy covers the Google data it uses.

What it accesses

  • Google Calendar events (scope calendar.events): to create events the owner asks for, list them, and delete an event the owner asks to remove.
  • Gmail, read-only (scope gmail.readonly): to read a specific email the owner points to, so an event's date, time and place can be taken from it.

How the data is used

Only to carry out the owner's own requests. It is not used for advertising, profiling, analytics or training AI models, and it is not sold or shared with anyone.

Where the data is kept

The Google sign-in token is stored only on the owner's computer, in a file only they can read. Email content is read on demand to create an event and is not stored by slack-hub. Event details live in the owner's own Google Calendar.

Third parties

To understand a request, the owner's own AI assistant may process the text of the message and the email it refers to, on the owner's behalf. Nothing is sent to anyone else.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions, and by deleting the token file on the owner's computer.

Google API Services User Data Policy

slack-hub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
