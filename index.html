slack-hub

A personal tool. Not a public service.

slack-hub is a small script that runs on one person's own computer. It connects their private Slack messages to their own notes and their own Google account, so they can send themselves a message like "put this interview in my calendar" and have the event appear.

What it does with Google:

  • Google Calendar: creates, lists and deletes events on the owner's own calendar, with reminders.
  • Gmail (read-only): reads an email the owner points it to, so the event details can be taken from it. It never sends, changes or deletes mail.

It has exactly one user, its owner. Nobody else can sign in to it, and it is not offered to anyone.
